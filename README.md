# 💈 Sistema de Agendamentos

Este projeto consiste em um sistema de agendamentos desenvolvido inicialmente para barbearias, com o objetivo de facilitar o gerenciamento de horários, clientes e serviços. A proposta é que, futuramente, o sistema possa ser adaptado para diversos outros tipos de estabelecimentos, como salões de beleza, clínicas, estúdios e outros negócios que trabalham com agendamentos.

> 🚧 Projeto em desenvolvimento.

## Objetivo

Criar uma plataforma simples, moderna e intuitiva para facilitar o processo de agendamento, proporcionando praticidade tanto para os clientes quanto para os administradores do estabelecimento.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Tecnologias Planejadas

- Banco de Dados (MySQL)
- PHP para integração com o banco de dados
- Sistema de autenticação de usuários
- Armazenamento seguro de informações
- Área administrativa

## Funcionalidades

### Já desenvolvidas
- Interface responsiva
- Estrutura inicial do sistema
- sistema de login (mas sem segurança por enquanto)
- Páginas de navegação

### Em desenvolvimento
- Cadastro de clientes
- Sistema de login (com segurança)
- Agendamento de horários
- Painel administrativo
- Banco de dados para armazenamento das informações
- Gerenciamento de horários e serviços

## Objetivo Futuro

O sistema será desenvolvido de forma modular, permitindo sua adaptação para diferentes segmentos comerciais que necessitem de um sistema de agendamento.
